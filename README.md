# لوحة العيادة الطبية – سكن 52

تم نشر المنصة على الاستضافة:

**https://clinic52-youbi.mohamedyoubi.chatgpt.site/**

يفتح مسؤول النظام الرابط لأول مرة ويستخدم رمز التهيئة المرسل له ليختار اسم المستخدم وكلمة المرور، ثم ينشئ حتى خمسة حسابات للعيادة من داخل الموقع. حساب المسؤول منفصل عن الخمسة. لا يوجد تسجيل عام للمستخدمين، وتحتاج البيانات والتقارير وملفات Excel إلى جلسة دخول صالحة.

النسخة السحابية الكاملة محفوظة كأرشيف مصدر في الفرع الخاص [clinic52-cloud-v1](https://github.com/youbi41-ui/dachbord/tree/clinic52-cloud-v1). يحتوي الأرشيف على كود الواجهة والخادم السحابي وقاعدة D1 وحفظ Excel في R2 ومخطط الترحيل والفحوص. لا يحتوي رمز التهيئة أو كلمات مرور أو بيانات تشغيل.

الملفات الموجودة في الفرع main هي النسخة المحلية السابقة بخادم Python، ويمكن تشغيلها عبر SETUP_ACCOUNTS.bat ثم START_SERVER.bat بعد تثبيت Python 3.10 أو أحدث. مجلد runtime ينشأ محليًا أثناء التشغيل؛ لا ترفع سجلات المرضى أو قواعد البيانات أو كلمات المرور إلى GitHub.
