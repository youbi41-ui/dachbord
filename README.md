# لوحة العيادة الطبية – سكن 52

مشروع لوحة ويب للعيادة الوحيدة في سكن 52. يحتوي المستودع على واجهة عربية واتجاه RTL، شاشة إدخال، ملفات العمال، وسجل الزيارات والأدوية ودوام الكادر.

## حدود المستودع

هذا المستودع الخاص يحفظ ملفات المشروع فقط؛ لا يشغّل الموقع على الإنترنت بذاته. الواجهة تتطلب خادمًا متصلًا بها عبر واجهة API لتسجيل الدخول وحفظ البيانات المشتركة. لم تتم إضافة كلمات مرور أو قاعدة بيانات تشغيل أو بيانات مرضى حقيقية إلى GitHub. ملف `dashboard.html` في هذا المستودع لا يحتوي سجلات عرض تجريبية.

## تشغيل محلي

1. يتطلب Python 3.10 أو أحدث.
2. شغّل `SETUP_ACCOUNTS.bat` لإنشاء كلمة مرور لحساب الإدارة وحساب العيادة الأول.
3. شغّل `START_SERVER.bat` وافتح `http://127.0.0.1:8080`.
4. بعد دخول مسؤول النظام، افتح «إدارة حسابات العيادة». يمكن إضافة حسابات مستقلة حتى خمسة حسابات للعيادة، وإعادة تعيين كلمة المرور أو تعطيل الحساب. حساب الإدارة منفصل عن هذا العدد.

تُحفظ السجلات في قاعدة SQLite محلية ويُنشأ ملف Excel داخل مجلد `runtime` أثناء التشغيل. لا ترفع مجلد التشغيل أو أي ملف قاعدة بيانات أو كلمات مرور إلى هذا المستودع.

## الملفات

- `dashboard.html`: واجهة لوحة القيادة والإدخال.
- `server/clinic_server.py`: خادم الدخول والصلاحيات والبيانات.
- `server/excel_store.py`: إنشاء نسخة Excel من السجلات.
- `clinic_entry.js` و`clinic_core.js` و`clinic_excel.js` و`worker_files.js`: ملفات المصدر التي تُدمج داخل صفحة الواجهة عند البناء.

## نشر الموقع

قبل نشره على رابط عام، يلزم تشغيل الخادم وقاعدة البيانات خلف HTTPS في استضافة تدعم Python أو نقل الواجهة البرمجية والتخزين إلى خدمة سحابية. نشر صفحة HTML وحدها لا يوفّر تسجيل دخول أو حفظًا مركزيًا؛ لذلك لا تعد صفحات GitHub Pages استضافة تشغيل لهذا الإصدار.
